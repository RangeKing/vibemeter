# VibeMeter 0.6.0

## 中文

VibeMeter 0.6.0 将个人 Agent 治理能力收进现有的 Session Replay、Attention、Notch 和 Sources，让每个判断都尽量回到本机可核查的证据。

### 新增

- **屏幕边缘侧栏**：在设置中开启左侧或右侧的独立面板；悬停展开、移开后延迟收起，支持固定、Escape、来源筛选、状态概览和跳回来源。原有顶部 Notch 保留。
- **macOS 毛玻璃界面**：主窗口加入原生 vibrancy 与半透明层，支持中英文、浅色/深色/系统外观，以及减少动态效果和降低透明度回退。
- **委派视图**：Session Replay 新增委派页签，根据规范事件还原父子 Agent、创建、委派、交接、恢复和汇合，并提供可缩放关系图、时间轨迹、筛选和证据下钻。
- **证据型治理提醒**：委派关系和异常显示证据等级、来源覆盖、规则版本、置信度与规范事件引用；只有精确、高置信度的等待、阻塞错误、重复创建失败和未完成交接才会进入既有 Attention / Notch。摘要不会暴露 Prompt、命令、工具参数或绝对路径。
- **只读 Memory Ledger**：Session Replay 新增按需加载的记忆视图，记录来源能够证明的记忆读取与写入活动，并可回到过程证据。读取不会被推断为写入，记忆正文、Prompt、Response、命令、工具参数、环境变量和绝对路径均不保存。
- **更细的来源能力说明**：Source Capabilities 更新为 per-signal v2，Sources 页面展示委派能力的真实覆盖范围；证据不足时明确显示部分记录或未记录。
- **官方模型价格**：刷新官方 API 价格目录，加入 Claude Fable 5.1 与 GPT 6 Astra 的标准输入、缓存和输出价格；解析器明确使用 Standard 表，并保留可追溯的模型兼容别名。
- 感谢 CodeNotch / Vinz 提供边缘交互和弹簧动画参考，相关 MIT 声明保留在仓库中。

### 修复与改进

- 委派 Attention 会随最新证据的 24 小时窗口过期，并在对应分支结束后清理，避免已结束分支留下过期提醒。
- 价格目录变更后仍能识别历史模型名称，避免旧会话的成本估算因官方名称更新而丢失。

本版本不包含 Evolution Loop、记忆库编辑、自动学习、Agent 配置修改、OTLP、云同步、通用执行器或聊天界面。

## English

VibeMeter 0.6.0 brings personal-agent governance into the existing Session Replay, Attention, Notch, and Sources surfaces, keeping decisions tied to evidence that can be checked locally.

### New

- **Screen-edge sidebar**: Enable an independent panel on the left or right edge in Settings. Hover to unfold; leaving folds it after a short delay. Pinning, Escape, provider filtering, status summaries, and source jumps are supported. The existing top Notch remains available.
- **Native macOS glass**: The main window now uses native vibrancy and translucent layers, with bilingual copy, light/dark/system appearance, and reduced-motion and reduced-transparency fallbacks.
- **Delegation view**: Session Replay now reconstructs parent and child agents, spawns, delegation, handoffs, resumes, and joins from canonical events, with a zoomable relationship graph, timeline, filters, and evidence drill-down.
- **Evidence-bound governance signals**: Delegation relationships and anomalies expose evidence level, source coverage, rule version, confidence, and canonical event references. Only exact, high-confidence waiting, blocking errors, repeated spawn failures, and unfinished handoffs enter the existing Attention / Notch flow. Summaries do not expose prompts, commands, tool arguments, or absolute paths.
- **Read-only Memory Ledger**: Session Replay adds a lazy-loaded Memory view for provider-verifiable memory reads and writes, with links back to Process evidence. Reads never imply writes; memory content, prompts, responses, commands, tool arguments, environment variables, and absolute paths are not stored.
- **More precise source capabilities**: Source Capabilities moves to per-signal v2, and Sources shows the actual delegation coverage available from each provider. Incomplete evidence remains Partial or Not recorded.
- **Official model pricing**: Refreshes the official API pricing catalog with standard input, cached-input, and output rates for Claude Fable 5.1 and GPT 6 Astra. The parser explicitly selects the Standard table and keeps traceable compatibility aliases for renamed models.
- Thanks to CodeNotch / Vinz for the edge-interaction and spring-motion reference; its MIT notice remains in the repository.

### Fixes and improvements

- Delegation Attention now expires within a 24-hour window based on its latest evidence and is cleared when the corresponding branch ends, preventing stale reminders for finished work.
- Historical model names remain recognizable after a pricing-catalog rename, so cost estimates for older sessions do not disappear.

This version does not include Evolution Loop, memory-store editing, automatic learning, agent-configuration changes, OTLP, cloud sync, a general executor, or a chat interface.
