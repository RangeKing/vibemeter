# VibeMeter 0.6.0 版本说明

> 开发分支：`feat/v0.6.0-edge-sidebar-glass`。本地验证和安装包记录见 [QA](../qa/v0.6.0-edge-sidebar-glass.md)；正式发布、Intel 安装包与 Apple 公证需单独验证。

## 中文

- 新增可选的左/右屏幕边缘侧栏，支持悬停展开、450 ms 延迟收起、弹簧和逐项动画、来源筛选、固定、Escape 收起与跳回来源；原有顶部 Notch 保留。
- 主窗口加入 macOS 原生毛玻璃和半透明界面层，中英文、浅深色与辅助功能回退保持一致。
- 从官网刷新 API 价格，支持 Claude Fable 5.1 和 GPT 6 Astra 的标准输入、缓存与输出计价；解析器明确选择 Standard 表，并保留折叠的旧模型价格。未知变体不再按宽泛前缀误套基础模型价格。
- 感谢 CodeNotch / Vinz 的边缘交互和动画参考，保留 MIT 声明。

VibeMeter 0.6.0 一次完成 Governance Foundation、Delegation Trace 与只读 Memory Ledger，把现有 Session Replay、Attention、Notch 和 Sources 收口为可解释的个人 Agent 治理层。

- Session Replay 新增“委派”视图，根据规范事件重建父子 Agent、创建、委派、交接、恢复与汇合。
- 关系图支持缩放、平移、筛选、证据下钻和大图列表回退；时间轨迹与关系图共享选择状态。
- 每条关系和异常都带有证据等级、来源覆盖、算法或规则版本、置信度及规范事件引用。
- 已观测、已派生、已推断、用户确认与不可用严格区分；证据不足时显示部分记录或未记录。
- Claude Code 与 Codex 优先提供真实可观察的委派信号，其他来源按实际能力显示部分支持或未记录。
- 需要用户接管的精确等待、阻塞错误、重复创建失败与未完成交接可进入既有 Attention / Notch；短摘要不会显示 Prompt、命令、工具参数或绝对路径。
- Source Capabilities 升级为 per-signal v2，Sources 页面新增 Delegation 能力说明。
- Session Replay 同时新增按需加载的“记忆”视图，用时间轨迹还原来源能够证明的记忆读取与写入活动。
- 每条记忆访问都包含规范事件引用、证据等级、来源覆盖、算法版本和置信度，并可回到“过程”中的对应证据。
- 读取不会被推断为写入，派生证据不会显示为已观测；当前 Codex 只支持 `partial` / `derived` 读取，其写入、Claude Code 读写及其他来源均保持 `unavailable`。
- Memory Ledger 使用稳定哈希身份，重复、乱序、重启和重索引不会制造重复记录；自动投影可 tombstone，用户确认与既有治理反馈保留。
- Memory Ledger 不保存记忆正文、Prompt、Response、命令、工具参数、环境变量或绝对路径，也不进入 Attention / Notch。
- SQLite schema 30 加入 Delegation relation，schema 31 加入 Memory access；两者均通过 canonical evidence link、查询索引和安全升级回归保持可重建。

本版本不包含 Evolution Loop、记忆库编辑、自动学习、Agent 配置修改、OTLP、云同步、通用执行器或聊天界面。

## English

- Adds an optional left/right screen-edge sidebar with hover unfolding, a 450 ms fold grace, spring and staggered motion, provider filtering, pinning, Escape and source jumps. The top Notch remains available.
- Adds native macOS vibrancy and translucent interface layers, with bilingual copy, light/dark themes and accessibility fallbacks.
- Refreshes official API pricing, including Claude Fable 5.1 and GPT 6 Astra standard input, cache and output rates. The parser explicitly selects Standard and retains collapsed older-model rows. Unknown variants no longer inherit prices through a broad prefix match.
- Credits CodeNotch / Vinz for edge interaction and motion, retaining its MIT notice.

VibeMeter 0.6.0 delivers Governance Foundation, Delegation Trace, and the read-only Memory Ledger together, turning Session Replay, Attention, Notch, and Sources into an explainable personal-agent governance layer.

- Session Replay gains a Delegation view that reconstructs parent/child agents, spawns, delegation, handoffs, resumes, and joins from canonical events.
- The directed graph supports zoom, pan, filters, evidence drill-down, and a list fallback; the timeline shares its selection state with the graph.
- Every relationship and anomaly carries an evidence level, source coverage, algorithm or rule version, confidence, and canonical event references.
- Observed, derived, inferred, user-confirmed, and unavailable states remain distinct. Incomplete evidence is shown as Partial or Not recorded.
- Claude Code and Codex receive priority support from fields the current adapters can actually observe. Other providers stay truthfully partial or unavailable.
- Exact takeover signals can enter the existing Attention / Notch flow without exposing prompts, commands, tool arguments, or absolute paths.
- Source Capabilities moves to per-signal schema v2, and Sources now shows Delegation capability.
- Session Replay also gains a lazy-loaded Memory view that places provider-verifiable memory read and write activity on a timeline.
- Every memory access carries canonical evidence references, evidence level, source coverage, algorithm version, and confidence, with a jump back to matching Process evidence.
- Reads never imply writes and derived evidence never appears as observed. Codex currently supports only `partial` / `derived` reads; Codex writes, Claude Code reads/writes, and all other providers remain `unavailable`.
- Stable hashed memory-access identities converge across duplicates, reordering, restart, and reindex. Automatic projections may be tombstoned while user confirmation and existing governance feedback remain intact.
- Memory Ledger stores no memory content, prompts, responses, commands, tool arguments, environment variables, or absolute paths, and it never enters Attention / Notch.
- SQLite schema 30 adds Delegation relations and schema 31 adds Memory accesses; both remain rebuildable through canonical-evidence links, query indexes, and safe-upgrade regression coverage.

This version does not include Evolution Loop, memory-store editing, automatic learning, agent-configuration changes, OTLP, cloud sync, a general executor, or a chat interface.
