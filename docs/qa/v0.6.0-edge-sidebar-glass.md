# v0.6.0 edge sidebar, glass and pricing QA

Date: 2026-09-08. Branch: `feat/v0.6.0-edge-sidebar-glass`. Base: `0bdfa3f`.

## Automated checks

- `npm run pricing:update`: 71 models from seven official sources; Astra and Fable 5.1 rates inspected on their official pages.
- `npm run ci`: passes. Three Python pricing-parser tests; 10 i18n checks; 33 frontend test files / 146 tests; Rust fmt and Clippy with warnings denied; 274 Rust unit tests pass, three ignored. Two separate opt-in integration audits remain ignored.
- `npm run build --workspace @vibemeter/desktop`: passes. The existing roughly 1.77 MB main JS chunk warning remains; this is not a measured performance pass.
- Root and desktop package versions, npm lock, Cargo manifest/lock and Tauri configuration all agree on `0.6.0`.
- `git diff --check`: passes.

New regressions cover Standard-vs-Batch/Fast price selection, complete legacy model rows, Fable's discounted cache read and both cache-write durations, Astra standard rates, dated aliases, unknown variants, collapsed window dimensions, negative monitor origins, left/right geometry, hover grace/cancellation, pin/Escape, filtering, missing lifecycle evidence, empty/error states and failed source jumps.

## Native macOS checks

A local debug `.app` was launched against an isolated QA database with indexing and hooks disabled. No production database or source-agent configuration was changed.

Observed with native accessibility state and screenshots:

- Right edge, English, dark appearance; independent edge panel rendered at 360 × 580 points.
- Fold control and Escape collapse the panel. After settling, screenshot dimensions are 16 × 108 points, with no full-size invisible window remaining.
- Reopening and pinning work; the pin control reports its new state.
- The sidebar's settings button opens the main Settings page.
- Selecting Left changes the stored side; the left panel uses the mirrored rail and rounded corners.
- Selecting Chinese and Light updates both the main window and the independent panel.
- Main window renders with native Sidebar material configured under the transparent webview and matching native appearance.

Native screenshots are retained locally in `.scratch/v0.6.0-edge-sidebar-glass/`: `edge-right-en-dark.jpg`, `edge-left-zh-light.jpg`, `edge-folded.jpg`, and `settings-zh-light.jpg`. The native test database deliberately has no active source sessions.

## Browser fixture checks

A temporary development page rendered six synthetic sessions using the real sidebar component. English/dark and Chinese/light layouts were visually inspected. Provider selection reduces six sessions to three; the inner list scrolls while the footer stays visible; a rejected source jump displays an error and preserves the session and retry control. A missing lifecycle displays “Status not recorded” / “未记录状态”. This check caught and fixed insufficient Codex icon contrast on the dark surface. The fixture page was removed from the app directory afterward.

Local screenshots: `fixture-provider-error-en-dark.jpg`, `fixture-sessions-zh-light.jpg`. These are synthetic UI checks, not evidence of a successful jump into an actual source application.

## Delivery boundary

Source-jump success in live third-party applications, physical monitor hot-plug, full-screen Space transitions, and measured animation frame rate were not independently exercised in this run. Reduced-motion and reduced-transparency fallbacks are implemented, but system accessibility preference toggles were not changed during QA. No public release, tag, Intel artifact or Apple notarization is implied by local checks.
